PROJECT KA MAQSAD (PURPOSE)
================================================================================

Yeh ek SaaS-style Lead Generation & Automation Tool hai jo:
1. Internet par Shopify stores ko automatically dhundta hai (DuckDuckGo search se)
2. Har store ka brand name, email, niche nikalta hai
3. Store ki contact page dhundhta hai aur form automatically fill kar ke submit karta hai
4. Leads ko AI/ML models se score karta hai (High / Medium / Low quality)
5. Sab data ek dashboard par dikhaata hai (charts, tables, stats)

2. shopify_leads.py — Selenium Scraping Engine
================================================================================

Kya hai: Actual automation engine jo browser control kar ke internet se data collect karta hai.

Kyun use ki: Selenium Chrome browser ko programmatically control karta hai — form fill,
button click, page navigate sab automatic.

Kya kar rahi hai:

  Section          | Function             | Kya Karta Hai
  -----------------|----------------------|----------------------------------------------
  Stealth Driver   | create_driver()      | Chrome browser launch karta hai stealth mode mein — persistent profile, realistic User-Agent, automation flags disabled, full JS stealth patches
  Progress Tracker | update_status()      | UI par real-time progress update karta hai (status bar, logs)
  Human Typing     | human_type()         | Form fields mein insaan jaisi typing — variable speed, word pauses, thinking gaps
  Human Scroll     | human_scroll()       | Page scroll karta hai — 80% neeche, 20% upar (natural pattern)
  Mouse Movement   | human_move_to()      | Mouse ko element tak naturally move kar ke click karta hai (ActionChains)
  Thinking Pause   | maybe_pause()        | 25% chance se random "content reading" pause
  Page Warm-up     | warm_up_page()       | Page visit ke baad pehle scroll + random link hover (natural browsing)
  Email Extract    | extract_emails()     | Page HTML se email addresses regex se nikalta hai
  Store Verify     | is_real_shopify_store() | Check karta hai ke website sach mein Shopify store hai ya nahi
  Brand Name       | extract_brand_name() | Page title se brand name extract karta hai
  Niche Detect     | detect_niche()       | Keywords ke basis par niche identify karta hai (headwear, clothing, fitness, etc.)
  Contact Finder   | find_contact_page()  | Website par contact page dhundhta hai (links scan + standard paths try)
  Form Filler      | fill_form()          | Contact form ke fields (name, email, company, message) automatically fill karta hai user ke templates se
  Form Submit      | try_submit_form()    | Submit/Send button dhundh kar human-like click karta hai
  Link Collection  | collect_all_links()  | DuckDuckGo par 5 queries x 5 pages search kar ke Shopify store links collect karta hai
  Store Processing | process_stores()     | Har store visit -> verify -> email extract -> contact page find -> form fill -> submit -> database save
  DB Save          | save_to_database()   | Lead ko buyers table mein INSERT karta hai
  Settings Load    | load_user_settings() | User ka name, email, company, templates database se load karta hai
  Main Entry       | scrape()             | Main function jo app.py call karta hai — driver create -> links collect -> stores process -> cleanup

Key Libraries Used:
  - Selenium       — Browser automation (Chrome control)
  - ActionChains   — Natural mouse movements
  - WebDriverWait  — Smart element waiting
  - sqlite3        — Database operations
  - re             — Email regex extraction


3. NLP.py — Text Cleaning & Relevance Labeling
================================================================================

Kya hai: NLP (Natural Language Processing) script jo raw scraped data ko clean aur label karti hai.

Kyun use ki: Scraped data noisy hota hai (special characters, duplicates, invalid emails).
NLP se data clean aur structured banta hai.

Kya kar rahi hai:

  Step | Function         | Detail
  -----|------------------|----------------------------------------------
  1    | Oracle Connect   | Oracle Database se connect ho kar raw buyers data fetch karta hai
  2    | clean_text()     | Brand name aur niche se special characters hata kar lowercase clean text banata hai
  3    | valid_email()    | Email address validate karta hai (@ aur . check)
  4    | Remove Duplicates| Same website wali duplicate entries hata deta hai
  5    | label_buyer()    | Scoring system: relevant keywords (headwear, clothing, fashion, etc.) + valid email = score. Score >= 2 toh "Relevant"
  6    | Save CSV         | Clean data clean_buyers.csv mein save karta hai
  7    | Update Oracle    | is_relevant, relevance_reason, score_reason columns Oracle mein update karta hai

Key Libraries: pandas, re, oracledb

NOTE: Yeh script Oracle Database se connect hoti hai (standalone script hai, Flask app
se separately run hoti hai). Flask app SQLite use karti hai.


4. ML.py — Machine Learning Lead Scoring
================================================================================

Kya hai: AI models train kar ke har lead ko score (0-100) aur category (High/Medium/Low) deti hai.

Kyun use ki: Manual lead quality check mushkil hai. ML automatically patterns learn
kar ke predict karta hai ke konsa lead valuable hai.

Kya kar rahi hai:

  Step | Detail
  -----|----------------------------------------------
  1    | Oracle Database se buyer data fetch karta hai
  2    | Features Engineer karta hai: valid_email, contact_available, brand_length, website_length, niche_encoded
  3    | Data ko 80% train / 20% test mein split karta hai
  4    | 3 Models Train karta hai: Random Forest (200 trees), Decision Tree, Logistic Regression
  5    | Accuracy compare karta hai aur best model (Random Forest) choose karta hai
  6    | Graphs Generate karta hai: Accuracy Comparison, Confusion Matrix, ROC Curve, Feature Importance
  7    | Lead Score calculate karta hai (0-100) using Random Forest probability
  8    | Category Assign karta hai: Score >= 80 -> High, >= 50 -> Medium, < 50 -> Low
  9    | Model ko buyer_model.pkl mein save karta hai (reuse ke liye)
  10   | Scores Oracle Database mein update karta hai
  11   | Final data buyers_with_scores.csv mein save karta hai

Key Libraries: scikit-learn, pandas, numpy, matplotlib, joblib, oracledb

================================================================================
DATABASE SCHEMA
================================================================================

Database: database.db (SQLite)

TABLE 1: users
  Column         | Type      | Detail
  ---------------|-----------|----------------------------------------------
  id             | INTEGER   | Primary Key, Auto Increment
  username       | TEXT      | Unique, Not Null
  email          | TEXT      | User email
  password_hash  | TEXT      | Not Null (SHA256 hashed)
  role           | TEXT      | "admin" ya "user" (default: "user")
  is_blocked     | INTEGER   | 0 (active) ya 1 (blocked)
  full_name      | TEXT      | User ka full name (settings se)
  company_name   | TEXT      | Company name (settings se)
  sender_email   | TEXT      | Outreach email (settings se)
  created_at     | TIMESTAMP | Account creation date

TABLE 2: buyers
  Column         | Type      | Detail
  ---------------|-----------|----------------------------------------------
  buyer_id       | INTEGER   | Primary Key, Auto Increment
  brand_name     | TEXT      | Scraped store ka brand name
  email          | TEXT      | Store ka email address
  website        | TEXT      | Store ki website URL
  niche          | TEXT      | Detected niche (headwear, clothing, etc.)
  contact_page   | TEXT      | Contact page URL
  source_url     | TEXT      | Original search result URL
  status         | TEXT      | "submitted" / "form_not_filled" / "no_contact_page" / "error"
  is_relevant    | INTEGER   | 0 ya 1 (NLP se labeled)
  lead_category  | TEXT      | "High" / "Medium" / "Low" (ML se scored)
  country        | TEXT      | Target country
  created_at     | TIMESTAMP | Lead creation date
  generated_by   | INTEGER   | Foreign Key -> users.id (kis user ne generate kiya)

TABLE 3: message_templates
  Column         | Type      | Detail
  ---------------|-----------|----------------------------------------------
  id             | INTEGER   | Primary Key, Auto Increment
  user_id        | INTEGER   | Foreign Key -> users.id
  name           | TEXT      | Template ka naam
  template_text  | TEXT      | Template text with placeholders: {brand}, {niche}, {sender_name}, {company_name}

TABLE 4: export_logs
  Column         | Type      | Detail
  ---------------|-----------|----------------------------------------------
  id             | INTEGER   | Primary Key, Auto Increment
  user_id        | INTEGER   | Foreign Key -> users.id
  username       | TEXT      | Export karne wale ka username
  total_leads    | INTEGER   | Total leads exported
  export_date    | TIMESTAMP | Export ki date/time

RELATIONSHIPS:
  - users (1) ---> (Many) buyers         [generated_by -> users.id]
  - users (1) ---> (Many) message_templates [user_id -> users.id]
  - users (1) ---> (Many) export_logs     [user_id -> users.id]

COMPLETE DATA FLOW
================================================================================

Step-by-step:

  1. User login kar ke "Generate Leads" page par jata hai
  2. Keyword (e.g. "fashion"), Country, Max Leads enter kar ke "Start" click karta hai
  3. app.py background thread mein shopify_leads.py ka scrape() call karta hai
  4. Selenium Chrome open karta hai (stealth mode) aur DuckDuckGo par search karta hai
  5. Results se Shopify store links collect karta hai (5 queries x 5 pages)
  6. Har store visit kar ke brand name, email, niche extract karta hai
  7. Contact page dhundh kar form fill karta hai (user ke saved template se)
  8. Submit button click karta hai
  9. Lead ko database.db ke buyers table mein save karta hai
  10. Real-time progress UI par dikhai deta hai (progress bar + logs)
  11. Dashboard automatically updated data dikhata hai (charts + tables)

Flow Diagram:

  User clicks "Generate Leads"
       |
       v
  app.py -> api_start_scraper()
       |
       v
  shopify_leads.py -> scrape()
       |
       v
  DuckDuckGo Search (5 queries x 5 pages)
       |
       v
  Shopify Stores (Visit each store)
       |
       v
  Extract brand, email, niche
       |
       v
  Find Contact Page -> Fill form & Submit
       |
       v
  Save to database.db
       |
       v
  Dashboard (Charts & Tables)
